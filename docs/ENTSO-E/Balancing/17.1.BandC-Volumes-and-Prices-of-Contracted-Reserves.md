# 17.1.B&C Volumes and Prices of Contracted Reserves

> Part of the [Balancing](./README.md) collection · [API overview](../ENTSOe-docs.md)

Data view page in Transparency Platform:

[https://transparency.entsoe.eu/balancing/r2/amountAndPricesPaidOfBalancingReservesUnderContract/show](https://transparency.entsoe.eu/balancing/r2/amountAndPricesPaidOfBalancingReservesUnderContract/show)

> \*Note: You can exclude the parameter processType from the request to retrieve data for all Reserve Types in 1 ZIP response.
### Method: GET
>```
>{{baseUrl}}?documentType=A81&businessType=B95&processType=A52&Type_MarketAgreement.Type=A01&controlArea_Domain=10YCZ-CEPS-----N&periodStart=202309242200&periodEnd=202309252200
>```
### Query Params

|Param|value|
|---|---|
|documentType|A81|
|businessType|B95|
|processType|A52|
|Type_MarketAgreement.Type|A01|
|controlArea_Domain|10YCZ-CEPS-----N|
|periodStart|202309242200|
|periodEnd|202309252200|
|psrType|A04|
|offset|0|
