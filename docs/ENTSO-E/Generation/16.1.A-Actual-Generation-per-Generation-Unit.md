# 16.1.A Actual Generation per Generation Unit

> Part of the [Generation](./README.md) collection · [API overview](../ENTSOe-docs.md)

**Request limits:**

- Maximum time interval: 1 day
    
- Minimum time interval: 1 Market Time Unit
    

**Important notes:**

- Response from API is same irrespective of querying for Document Types A74 - Wind & Solar & A75 - Actual Generation Per Type
    
- Time series with inBiddingZone_Domain attribute reflects **generation** values while outBiddingZone_Domain reflects **consumption** values.
### Method: GET
>```
>{{baseUrl}}?documentType=A73&processType=A16&in_Domain=10Y1001A1001A796&periodStart=202501012200&periodEnd=202501022200
>```
### Query Params

|Param|value|
|---|---|
|documentType|A73|
|processType|A16|
|in_Domain|10Y1001A1001A796|
|periodStart|202501012200|
|periodEnd|202501022200|
|PsrType|B14|
|RegisteredResource|22WAMERCO000008L|
