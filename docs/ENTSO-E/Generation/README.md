# Generation

Part of the [ENTSO-E Transparency Platform RESTful API](../ENTSOe-docs.md) documentation.

If you would like to learn more about the data items under this domain please go to [this link](https://transparencyplatform.zendesk.com/hc/en-us/articles/12784099471764).

> **For most of the data items in the generation domain, the** [**PsrType**](https://transparencyplatform.zendesk.com/hc/en-us/articles/15856995130004) **parameter is optional. When this parameter is not used, API returns all available data for each production type for the queried interval and area. If the parameter is used, data will be returned only for the specific production type requested.**
