# 6.1.A Actual Total Load

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view in Transparency Platform (old GUI)](https://transparency.entsoe.eu/load-domain/r2/totalLoadR2/show)

<u><b>Limits</b></u>:

- One year range limit applies
    
- Minimum time interval in query response is one MTU period
### Method: GET
>```
>{{baseUrl}}?documentType=A65&processType=A16&outBiddingZone_Domain=10YCZ-CEPS-----N&periodStart=202303030000&periodEnd=202303060000
>```
### Query Params

|Param|value|
|---|---|
|documentType|A65|
|processType|A16|
|outBiddingZone_Domain|10YCZ-CEPS-----N|
|periodStart|202303030000|
|periodEnd|202303060000|
