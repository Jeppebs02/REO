# 6.1.B Day-ahead Total Load Forecast

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view page in Transparency Platform (old GUI)](https://transparency.entsoe.eu/load-domain/r2/totalLoadR2/show)

**Limits**:

- One year range limit applies
- Minimum time interval in query response is one day
### Method: GET
>```
>{{baseUrl}}?documentType=A65&processType=A01&outBiddingZone_Domain=10YCZ-CEPS-----N&periodStart=202308140000&periodEnd=202308170000
>```
### Query Params

|Param|value|
|---|---|
|documentType|A65|
|processType|A01|
|outBiddingZone_Domain|10YCZ-CEPS-----N|
|periodStart|202308140000|
|periodEnd|202308170000|
