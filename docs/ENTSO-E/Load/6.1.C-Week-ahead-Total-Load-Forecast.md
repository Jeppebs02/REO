# 6.1.C Week-ahead Total Load Forecast

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view page in Transparency Platform (old GUI)](https://transparency.entsoe.eu/load-domain/r2/weekLoad/show)

**Limits**:

- One year range limit applies
- Minimum time interval in query response is one week
### Method: GET
>```
>{{baseUrl}}?documentType=A65&processType=A31&outBiddingZone_Domain=10YCZ-CEPS-----N&periodStart=202308132200&periodEnd=202308202200
>```
### Query Params

|Param|value|
|---|---|
|documentType|A65|
|processType|A31|
|outBiddingZone_Domain|10YCZ-CEPS-----N|
|periodStart|202308132200|
|periodEnd|202308202200|
