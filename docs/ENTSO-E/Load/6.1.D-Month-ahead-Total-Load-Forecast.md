# 6.1.D Month-ahead Total Load Forecast

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view page in Transparency Platform (old GUI)](https://transparency.entsoe.eu/load-domain/r2/monthLoad/show)

**Limits**:

- One year range limit applies
- Minimum time interval in query response is one month
### Method: GET
>```
>{{baseUrl}}?documentType=A65&processType=A32&outBiddingZone_Domain={{outBiddingZone_Domain}}&periodStart=202307022200&periodEnd=202308062200
>```
### Query Params

|Param|value|
|---|---|
|documentType|A65|
|processType|A32|
|outBiddingZone_Domain|{{outBiddingZone_Domain}}|
|periodStart|202307022200|
|periodEnd|202308062200|
