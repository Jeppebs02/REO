# 6.1.E Year-ahead Total Load Forecast

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view page in Transparency Platform](https://transparency.entsoe.eu/load-domain/r2/yearLoad/show)

**Limits**:

- One year range limit applies
- Minimum time interval in query response is one year
### Method: GET
>```
>{{baseUrl}}?documentType=A65&processType=A33&outBiddingZone_Domain=10YCZ-CEPS-----N&periodStart=202301012300&periodEnd=202312312300
>```
### Query Params

|Param|value|
|---|---|
|documentType|A65|
|processType|A33|
|outBiddingZone_Domain|10YCZ-CEPS-----N|
|periodStart|202301012300|
|periodEnd|202312312300|
