# 8.1 Year-ahead Forecast Margin

> Part of the [Load](./README.md) collection · [API overview](../ENTSOe-docs.md)

[Link to data view page in Transparency Platform (old GUI)](https://transparency.entsoe.eu/load-domain/r2/marginLoad/show)

**Limits**:

- One year range limit applies
    
- Minimum time interval in query response is one year
### Method: GET
>```
>{{baseUrl}}?documentType=A70&processType=A33&outBiddingZone_Domain=10YCZ-CEPS-----N&periodStart=202212312300&periodEnd=202312312300
>```
### Query Params

|Param|value|
|---|---|
|documentType|A70|
|processType|A33|
|outBiddingZone_Domain|10YCZ-CEPS-----N|
|periodStart|202212312300|
|periodEnd|202312312300|
