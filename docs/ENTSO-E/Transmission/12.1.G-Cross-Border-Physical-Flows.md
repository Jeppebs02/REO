# 12.1.G Cross-Border Physical Flows

> Part of the [Transmission](./README.md) collection · [API overview](../ENTSOe-docs.md)

Data view page in Transparency Platform:

[https://transparency.entsoe.eu/transmission-domain/physicalFlow/show](https://transparency.entsoe.eu/transmission-domain/physicalFlow/show)


> **Unlike Web GUI, API responds not netted values as data is requested per direction.**
### Method: GET
>```
>{{baseUrl}}?documentType=A11&out_Domain=10YDE-RWENET---I&in_Domain=10YBE----------2&periodStart=202308232200&periodEnd=202308242200
>```
### Query Params

|Param|value|
|---|---|
|documentType|A11|
|out_Domain|10YDE-RWENET---I|
|in_Domain|10YBE----------2|
|periodStart|202308232200|
|periodEnd|202308242200|
